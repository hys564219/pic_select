画像選別ツール PicSelect
=========================

オフラインで動くローカル画像選別ツールです。exe 1 つ、コピーするだけで使えます。ネット接続は不要。


【何をするツールか】

ネットから集めた画像まとめを整理するためのツールです。1 回につき 1 フォルダを処理します。
残したい画像に印を付けて、ひと通り見終わったら印の付いていない画像をごみ箱にまとめて移動します。

「千枚の写真から使える十枚を選ぶ」といった作業に向いています。


【動作環境】

Windows 10 / 11（64 ビット）。.NET、Python などのランタイムは不要で、
exe をダブルクリックするだけで起動します。

初回起動は 2〜5 秒ほど遅くなります（単一ファイルを一時フォルダに展開するため）。
2 回目以降は速くなります。


【基本的な使い方】

1. PicSelect.exe をダブルクリック
2. 左上の「フォルダを開く」を押すか、フォルダをウィンドウにドラッグ
3. 1 枚ずつ見ながら、右側のボタンで残すかどうかを決める
4. 全部見終わったら、右上の「未選択を削除」でまとめてごみ箱へ


【右側のボタン（上から順に）】

  残す          この画像に残す印を付けて次へ
  飛ばす        印を付けずに次へ（赤：飛ばす＝削除対象になります）
  前へ          1 枚前に戻る
  残す印        印のオン／オフだけ切り替える（画像は動きません）
  ─────────────────────
  前の印        前方で最も近い印の付いた画像へ
                前方に印がなければ先頭へ移動
  次の印        後方で最も近い印の付いた画像へ
                後方に印がなければ最後に処理した位置へ移動
  ─────────────────────
  元に戻す      直前の操作を取り消す

表示中の画像に印が付いていると、ボタン列の一番下に黄色の
「✓ 残す印あり」が出ます。


【表示言語】

上部ツールバー右側のドロップダウンで English / 中文 / 日本語 を切り替えられます。
画面表示もダイアログもすべて切り替わります。選んだ言語は次回起動時にも保持されます。


【ショートカット】

  スペース / K   残して次へ
  D / →          飛ばして次へ
  A / ←          前の画像
  S              印を付ける／外す（移動しない）
  [ / ]          前／次の印へ
  Ctrl+← / →     上と同じ
  Ctrl+Z         一つ戻す
  Ctrl+G         画像へ移動（番号またはファイル名の一部）
  Ctrl+O         フォルダを開く
  Ctrl+Delete    未選択をすべて削除
  Home / End     先頭／最後

  ホイール        カーソル位置を中心に拡大縮小
  ドラッグ        移動
  ダブルクリック  ウィンドウに合わせる ↔ 100%
  Enter / F       上と同じ
  0               100%


【移動の使い方】

Ctrl+G では次の 3 種類の入力ができます：
  37             37 枚目へ移動
  IMG_2045       ファイル名に IMG_2045 を含む最初の画像へ
  *2045*         ワイルドカード一致（上と同じ）


【削除について】

· 削除されるのは「残す印が付いていない」画像すべてです
· ごみ箱に移動するだけで、完全削除ではありません（復元できます）
· 削除前に件数を示す確認ダイアログが出ます
· 念のため先に「残すリストを出力」で一覧を保存しておくのがおすすめです
· 他のプログラムが使用中で削除できなかったファイルは別途表示され、
  残りのファイルの処理は止まりません


【途中で閉じて再開する】

· ページを送るたびに進捗（どの画像に印を付けたか、どこまで見たか）を保存します
· 次回起動時に続きから再開するか確認します
· 「最初から」を押すと今回の印を消して最初からやり直せます


【データの保存場所】

すべて exe と同じフォルダの picselect.data に入ります：

  picselect.data/session.json     現在の進捗（選別完了後に自動削除）
  picselect.data/settings.json    言語などの設定
  picselect.data/残すリスト_*.txt 手動で出力した一覧

· 完全に消したい場合は picselect.data フォルダを削除してください
· レジストリも AppData も使いません。ネット接続もしません
· 別の PC へ移すときは exe をコピーするだけです


【対応画像形式】

JPG / JPEG / PNG / BMP / GIF / TIFF / TIF / ICO / WebP

· WebP はシステムの WIC コーデックに依存します（Windows 10 1903 以降なら概ね利用可）
· HEIC / HEIF は「HEIF 画像拡張機能」のインストールが必要です
· カメラの RAW 形式には対応していません


【ページ送りが引っかからない理由】

現在位置の後ろ 10 枚、前 3 枚をバックグラウンドで先にデコードしておき、
ページを送るときはメモリ上のキャッシュをそのまま使います。ディスクからの
読み込みとデコードが発生しません。メモリ使用量には上限があるので、
枚数が多くても際限なく増えることはありません。

フル解像度のデコードは拡大表示したときだけ、バックグラウンドで
こっそり差し替えます。


【低スペックのノート PC では】

· ウィンドウサイズは画面の作業領域に合わせて縮むので、タスクバーに隠れません
· デコードのスレッド数は CPU コア数に応じて調整します。2 コアのマシンでは
  2 スレッドだけにして、画面操作の邪魔をしません
· メモリキャッシュの上限は物理メモリで決まります：5GB 未満は 220MB、
  9GB 未満は 320MB、それ以上は 420MB
· 拡大時、4096 ピクセルを超える画像は長辺 4096 でデコードします。
  1080p / 2K 画面では見た目はほぼ同じで、メモリ負荷はずっと軽くなります
· デュアル GPU のノート PC では既定のままで構いません。グラフィックドライバで
  強制的に専用 GPU を割り当てると、この種のツールではむしろ不安定になりがちです
