图片筛选工具 PicSelect
========================

一个离线的本地图片筛选小工具。单个 exe，拷走即用，不联网。


【它是做什么的】

用来整理从网上找来的图包。每次处理一个文件夹：
看到好的图片就标记好，一轮筛完，把没标记的图片全部扔进回收站。

适合「几百上千张图里快速挑出能用的那几张」这种活。


【运行要求】

Windows 10 / 11（64 位）。不需要安装 .NET、Python 或任何运行库，
双击 exe 就能跑。

第一次启动会慢 2-5 秒（单文件要先解压到临时目录），之后就快了。


【基本用法】

1. 双击 PicSelect.exe
2. 点左上角「打开文件夹」，或者直接把文件夹拖进窗口
3. 一张一张看，用右侧按钮决定留还是不留
4. 全部看完后，点右上角「删除未标记」把不要的一次性送进回收站


【右侧按钮，从上到下】

  保留          标记这张留下，并进入下一张
  跳过          不标记，进入下一张（红色：跳过就意味着会被删掉）
  上一张        回到上一张
  标记保留      只切换标记状态，画面不动（可以反复按）
  ─────────────────────
  上一个标记    跳到前面最近一张已标记的图
                前面没有已标记的就跳到第一张
  下一个标记    跳到后面最近一张已标记的图
                后面没有已标记的就跳到最后一张处理过的图
  ─────────────────────
  撤销          撤销上一步

当前这张被标记时，按钮栏最底部会出现一个黄色的「✓ 已标记保留」提示框。


【界面语言】

顶部工具栏右侧的下拉框可以切换 English / 中文 / 日本語，整个界面和提示框都会跟着变。
选过的语言会记下来，下次打开还是那个语言。


【快捷键】

  空格 / K      保留并下一张
  D / →         跳过，下一张
  A / ←         上一张
  S             标记 / 取消标记（不移动）
  [ / ]         上一个标记 / 下一个标记
  Ctrl+← / →    同上
  Ctrl+Z        撤销上一步
  Ctrl+G        跳转到指定图片（序号或文件名片段）
  Ctrl+O        打开文件夹
  Ctrl+Delete   删除所有未标记图片
  Home / End    第一张 / 最后一张

  滚轮          缩放（以鼠标位置为中心）
  拖拽          平移
  双击 / Enter  在「适应窗口」和「100%」之间切换
  0             100%
  F             同上


【跳转怎么用】

按 Ctrl+G 后可以输入三种东西：
  37            跳到第 37 张
  IMG_2045      跳到文件名包含 IMG_2045 的第一张
  *2045*        通配符匹配，同上


【关于删除】

· 删除的是「没有被标记保留」的所有图片
· 文件进回收站，不是永久删除，可以从回收站还原
· 删除前会弹确认框，写明数量
· 建议先点「导出保留清单」存一份，多一道保险
· 被其他程序占用、删不掉的文件会单独列出来，不影响其他文件


【中途关掉再开】

· 每次翻页都会自动记住进度（标记了哪些、看到第几张）
· 下次打开会问要不要接着上次继续
· 点「重新开始」可以清掉本轮的标记，从头再筛一遍


【数据存在哪】

全部在 exe 同目录的 picselect.data 文件夹里：

  picselect.data/session.json     当前进度（筛选完成后自动删除）
  picselect.data/settings.json    语言等设置
  picselect.data/保留清单_*.txt   手动导出的清单

· 想彻底清除所有痕迹：直接删掉 picselect.data 文件夹
· 不写注册表，不写 AppData，不联网
· 换个文件夹或换台机器，把 exe 拷过去就行


【支持的图片格式】

JPG / JPEG / PNG / BMP / GIF / TIFF / TIF / ICO / WebP

· WebP 依赖系统的 WIC 编解码器，Windows 10 1903 以后一般都能读
· HEIC / HEIF 需要系统装了「HEIF 图像扩展」才能读
· 相机 RAW 格式不支持


【为什么翻页不卡】

工具会在后台提前解码当前位置后面 10 张、前面 3 张，
翻页时直接命中内存缓存，不需要现场读盘解码。
内存占用有上限，图再多也不会越用越大。

放大看细节时才会去解全分辨率，而且是后台静默替换，不会打断你。


【在低配笔记本上】

· 窗口尺寸会自动按屏幕工作区收缩，不会顶到任务栏下面
· 解码线程数按 CPU 核数自动调整，双核机器只开 2 个，不跟界面抢 CPU
· 内存缓存上限按物理内存自动定档：4G 机器 220MB，8G 机器 320MB，更大 420MB
· 放大看细节时，超过 4096 像素的图只解到 4096 长边，
  在 1080p / 2K 屏上肉眼无差别，但显存和内存压力小很多
· 双显卡笔记本建议保持默认，不要到显卡控制面板里强制指定独显，
  这类工具用核显反而更稳
